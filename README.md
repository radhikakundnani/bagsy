# Bagsy

Weather-aware packing lists for your trips. Tell Bagsy where you're going, when, and what you'll do, and it builds a packing checklist from the weather for those dates, your activities, trip type and trip length.

## Features
- Packing lists generated by a rule-based engine (temperature bands, rain/snow/wind/humidity, climate type, 20+ activities, trip type, trip length)
- Weather matched to your trip dates: a live forecast for trips in the next 5 days, and typical weather (same dates last year) for trips further away
- Tick items off, add your own, and get reminders for trips starting soon
- Accounts with JWT login and password reset

## Tech stack
React 18, Vite, Tailwind CSS, React Router · Node.js, Express 5, MongoDB (Mongoose) · JWT, bcrypt · OpenWeatherMap and Open-Meteo APIs

## Run locally
You need Node.js, a MongoDB connection string (a free MongoDB Atlas cluster works) and a free OpenWeatherMap API key.

```bash
# backend (http://localhost:5001)
cd server
cp .env.example .env   # then fill in MONGO_URI, JWT_SECRET, WEATHER_API_KEY
npm install
npm run dev

# frontend (http://localhost:3000)
cd client
npm install
npm run dev
```
